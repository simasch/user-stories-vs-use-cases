# Glossary

| Term                  | Definition                                                                                                   | Avoid              |
|-----------------------|--------------------------------------------------------------------------------------------------------------|--------------------|
| Course                | A training offered on fixed dates at a location, with a limited number of seats and a price.                 | Training, Event    |
| Course Administrator  | An employee of the course provider who publishes courses. Signs in with the role ADMIN.                     |                    |
| Participant           | A signed-in person who registers for courses. Signs in with the role USER.                                   | Attendee, Customer |
| Registration          | A participant's claim on a seat in a course, or on a place on its waiting list.                              | Booking            |
| Capacity              | The maximum number of confirmed registrations of a course.                                                   |                    |
| Seat                  | One unit of the capacity of a course. A confirmed registration holds one seat.                               |                    |
| Waiting List          | The ordered list of registrations of a course that wait for a free seat.                                     |                    |
| Registration Deadline | The last day on which participants can register for a course.                                               |                    |
| Cancellation Fee      | The amount in CHF a participant owes when cancelling a registration late.                                    |                    |
